# 功能清单（已冻结）

以 opencode v1 TUI 的功能集为准绳，不追求 OpenChamber 级别的"Agentic 开发环境"。

## 核心功能（自己做）

| # | 功能 | 备注 |
|---|---|---|
| 1 | 左侧会话列表（常驻侧栏） | 核心中的核心。新建/切换/删除/搜索/置顶/归档/排序（默认按最后活动时间）。范围见 docs/07 问题 c |
| 2 | 对话流 | 流式输出、markdown + 代码高亮、thinking 折叠 |
| 3 | 工具调用卡片 | 名称 + 参数摘要 + 运行状态 + 结果折叠 |
| 4 | diff 展示 | 两处：工具卡片内变更视图 + 未提交变更页签（最小只读，`git status` + `git diff` 渲染） |
| 5 | 权限确认 | 卡片式 允许/拒绝/总是允许，按钮触控友好 |
| 6 | 输入框 | 多行、图片粘贴；每会话草稿存服务端，跨设备续写 |
| 7 | agent 切换 | 下拉（TUI Tab 键的等价物） |
| 8 | 模型切换 | /models 的等价物 |
| 9 | todo 任务渲染 | 引擎 todo 工具的结构化展示 |
| 10 | 图片输出查看 | 多模态输出、截图内联 |
| 11 | token/费用状态条 | 底部状态栏 |
| 12 | 基础命令 | /compact /clear /new /undo |
| 13 | 中断 | 停止按钮 |
| 14 | 文件树 + 只读预览 | 含 @引用进对话（浏览与对话的闭环，独立工具做不到） |

## 会话列表元数据（壳层自有，服务端 sqlite 存储）

- 置顶 pin/unpin、排序、归档（收起不删）、输入历史（上箭头调出）
- 状态标识：运行中/等待权限/空闲/出错（列表小圆点）
- 未读标记：切走后有新消息的会话显示计数
- 自动命名展示 + 手动重命名
- 会话图标/来源标识（哪个 agent 跑的、人工 or agent 创建）
- 批量清理/归档旧会话
- 单会话导出/分享（senpi 引擎自带 `--export HTML`，可能白得）
- 消息级操作：复制 markdown 原文、重试、编辑后重发（引擎支持度待验证）

## 项目管理

项目 = 一个工作目录（沿用引擎的 project/directory 概念）：

- 项目列表与切换（顶栏下拉或侧栏分组）；会话按项目分组
- 最近打开/默认项目（打开 web 直接落到上次项目）
- 项目级偏好（记住每项目偏好的 agent/模型）
- 添加项目：路径输入或文件树选择（服务端需列目录/验证路径的小接口）

## 外链（独立自托管工具，反代挂路径）

| 路径 | 工具 | 用途 |
|---|---|---|
| /git | cgit（纯看）或 Gitea（要托管体验时） | 历史、blame、分支对比。注意：这类工具都不显示未提交变更，所以"未提交变更总览"留在核心里自己做 |
| /files | filebrowser（按需） | 上传/下载/重命名/在线编辑等完整文件管理 |

## 明确不做

PWA/推送通知、Git 写操作（stage/commit/push 让 agent 自己干）、multi-run 多模型并行、diff 带逛、PR/GitHub 集成、多服务器聚合、relay/隧道产品化（手机连不进局域网时用一条 cloudflare tunnel 命令解决）、VS Code/桌面壳、主题切换、分栏并排多会话、消息收藏/标签、团队协作。

## 手机端适配要求（约束，不是功能）

- 窄屏单栏；会话栏抽屉化；Git/文件/变更入口底部标签化
- 权限按钮/折叠/长按复制触控化
- 长会话虚拟列表 + SSE 增量渲染（性能与流量）
- 架构上会话在服务端跑：手机锁屏/杀浏览器不影响执行，回来刷新即见结果；无主动推送通知（PWA 已砍，待最终确认见 docs/07 问题 e）
